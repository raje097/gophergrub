## Project Description

Gopher Grub helps UMN students decide where to eat on campus. Students can browse
the university's dining halls, see community ratings, and leave their own reviews —
turning scattered word-of-mouth opinions into a single, searchable place to find the
best food on campus.

**Key features**
- Browse campus dining halls and view their current ratings
- Submit ratings and reviews for each dining hall
- Live updates via an asynchronous frontend (no page reloads)

## Running Locally

**Prerequisites:** [Node.js](https://nodejs.org/) (which includes npm)

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/gopher-grub.git
cd gopher-grub

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

The app will be available at `http://localhost:3000` (update the port if yours differs).
